# Vinilmanía

Sitio web de Vinilmanía, taller de diseño, impresión, rotulación y personalización en Cuernavaca, Morelos.

**Ver la web:** https://jorgediezfelix-ops.github.io/vinilmania/

## Páginas

Inicio, Servicios, Productos personalizados, Galería, Nosotros, Proceso, Preguntas frecuentes y Contacto.

El sitio usa HTML, CSS y JavaScript estándar, con fotografías y tipografías locales. No requiere compilación ni dependencias de JavaScript.

## Editar

- Los archivos `.html` contienen el contenido de cada página.
- `style.css` define el diseño general; `header.css`, el encabezado y los menús.
- `app.js` controla la navegación móvil, los filtros, la galería y el formulario.
- `assets/` contiene imágenes, fuentes y sus licencias.

Los enlaces son relativos para funcionar tanto en local como en GitHub Pages. Para una vista previa, abre `index.html` o ejecuta `python3 -m http.server 4173` desde esta carpeta.

## Publicar cambios

GitHub Pages publica desde la raíz de la rama `main`. Guarda los cambios, crea un commit y súbelos a `main`; GitHub actualizará el sitio.

## Contenido e imágenes

La información del negocio y las fotografías de trabajos reales provienen de [vinilmania.net](https://vinilmania.net/). Las imágenes generadas que ilustran ideas se identifican como conceptuales en la web. Las fuentes Barlow y DM Sans incluyen sus licencias en `assets/`.

El formulario prepara un mensaje de WhatsApp para que la persona lo revise y envíe. No almacena datos ni envía mensajes automáticamente.
